# ♟️ Chess Analysis — VinesDev

Website analisis catur berbasis browser. Bisa gerakkan bidak, lihat label kualitas langkah (Brilliant, Best, Blunder, dll), cari skakmat, import PGN/FEN, dan review game.

## ✨ Fitur
- ♟️ Papan catur interaktif (drag & klik)
- 🏷️ Label kualitas langkah
- 💡 Saran best move
- 🎯 Cari skakmat (mate in 1)
- 📥 Import PGN / FEN
- 🔍 Review game + deteksi blunder
- 📊 Eval bar
- ↩️ Undo / 🔄 Flip / ♻️ Reset

## 🚀 Cara Pakai
1. Clone repo
2. Buka `index.html` di browser, atau
3. Upload ke GitHub Pages (Settings → Pages → Deploy from branch)

## 🛠️ Teknologi
- [chess.js](https://github.com/jhlywa/chess.js)
- [chessboardjs](https://chessboardjs.com/)
- jQuery
